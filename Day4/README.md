# Shape Studio

A small Flask and OpenCV website that adds a line, rectangle, triangle, or circle to an uploaded image.

## Run locally

```powershell
cd D:\openCV\Day4
python -m pip install -r requirements.txt
python app.py
```

Open <http://127.0.0.1:5000> in your browser.

Uploaded images are limited to 10 MB. Finished images are stored in the `generated` folder and can be downloaded from the result screen.
